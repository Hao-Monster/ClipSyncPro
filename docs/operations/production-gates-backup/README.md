# 生产门禁规范与基线备份 (Production Gates Backup)

> 本目录备份生产环境的发布门禁基线、全量回归与容量安全检查策略。

## 1. 环境与架构原则

- **开发测试与生产共用同一套应用代码与底层架构**。
- **开发测试服务器（`bingo-dev`）**：
  - 采用**快速构建部署流程**，不等待全量回归、容量压测或业务验收门禁，确保特性快速交付与反馈。
- **生产环境（Production）**：
  - 上线前**必须严格通过**本目录所列出的全量门禁基线。

---

## 2. 生产门禁检查清单（Production Gates）

| 门禁分类 | 门禁项目 | 检查要求 | 验证方式 |
|---|---|---|---|
| **代码与构建** | 静态语法与 Linter | Go 代码 `golangci-lint` 无严重错误；C# 编译 0 警告 0 错误 | CI 自动化脚本 |
| **单元与集成** | 针对性与全量单测 | `go test -race ./...` 100% 通过；覆盖率达到 80%+ | CI 自动化测试 |
| **数据与迁移** | 数据库迁移门禁 | 启动前校验旧 Base64 图片行与旧 queue 行为 0；备份已验证可还原 | `clipsync-migrate --dry-run` 计划核验 |
| **安全与加密** | 敏感字段隔离 | 严禁明文敏感词入库；AES-256-GCM 密文与 PBKDF2 迭代轮次核对 | 自动化加解密测试套件 |
| **容量与并发** | 内存与流量上限 | 单条剪贴板图片内存有界（<=10MB）；同步队列并发有界（<=1000 items） | 压力测试与容量基线核验 |
| **版本核验** | 部署指纹与健康检查 | 远程 `/healthz` 响应 200；构建 Commit SHA 与 Git Tag 完全一致 | 部署后自动化巡检探针 |

---

## 3. 快速部署 vs 生产门禁对照

| 流水线特性 | 开发测试服务器 (`bingo-dev`) | 生产环境 (`production`) |
|---|---|---|
| **触发策略** | PR 合并或推送至开发/发布分支即刻触发 | 严格 Release Tag 触发 + 审批门禁 |
| **门禁范围** | 编译构建 + 针对性单测 + 快速健康探测 | 全量单测 + 静态分析 + 数据库迁移核验 + 业务验收 |
| **失败策略** | 失败即报警，开发分支快速修复 | 阻断发布，即刻自动回滚至上一稳定版本 |
| **业务验收** | 部署后由项目负责人针对性验收 | 发布前预验收 + 灰度验证后正式上线 |

---

## 4. 门禁恢复与备份归档

若后续开发测试流水线因快速迭代调整了某些严苛检查参数，可在生产发布前对照本目录文件还原生产检查标准。
